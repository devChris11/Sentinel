# Sentinel

AI-native behavior risk intelligence platform for security teams.

**Live demo:** https://sentinel-risk-monitoring.vercel.app/dashboard

**Full case study:** https://christo-fernando.com/projects/sentinel

**Storybook:** https://69996ecdf332957002fd55bb-mtdalakagg.chromatic.com/

Sentinel consolidates fragmented security tooling, threat detection, behavior analytics, and reporting, into a single console built around how security admins actually triage risk, not around the underlying data model. Designed and shipped in 4 days using an AI-native workflow.

Implementation notes and test verification are in `/docs`.

**Tech:** Next.js, React 19, TypeScript, shadcn/ui, Recharts, Storybook, Vitest, Playwright

**AI workflow:** Claude for design strategy, v0 for component generation, Cursor for integration and refinement
